## 📌 Назначение программы

Приложение предназначено для проведения экзаменационных сессий. Оно поочередно запрашивает данные студентов, случайным образом генерирует номер билета (от 1 до 20) и моментально записывает результат в журнал формата Excel (`journal.xlsx`).

---

## ⚙️ Основные возможности и параметры

> [!NOTE]
> 🟦 **Генерация билетов:** Автоматический рандомайзер случайного значения билета в диапазоне от **1 до 20**.

> [!TIP]
> 🟩 **Мгновенное сохранение (Fault Tolerance):** Файл сохраняется **сразу после ввода каждого студента**, а не при закрытии программы. При аварийном завершении данные гарантированно остаются в журнале.

> [!IMPORTANT]
> 🟪 **Интерактивный перехват `ESC`:** Выход из бесконечного цикла программы осуществляется нажатием клавиши `ESC` в момент ожидания ввода данных.

> [!WARNING]
> 🟧 **Валидация и обработка ошибок:**
> * Пустые строки не принимаются, пробелы по краям автоматически обрезаются.
> * Если файл `journal.xlsx` открыт в Excel, приложение выводит понятное предупреждение с предложением закрыть файл, предотвращая падение программы[cite: 2].

## 📋 Формат таблицы `journal.xlsx`

Если файл отсутствует в корне проекта, программа создаёт его автоматически вместе с шапкой[cite: 2]. Если файл уже существует — новые данные строго дописываются в конец без перезаписи прошлых записей[cite: 2].

| Колонка A | Колонка B | Колонка C | Колонка D |
| :--- | :--- | :--- | :--- |
| **Last name** | **First name** | **Номер билета** | **Дата и время** |

```text

4. Генерация: Билет № X -> Вывод в консоль
