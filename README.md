# Генератор экзаменационных билетов

Веб-приложение на Rust для выбора группы и студента, назначения экзаменационного билета и ведения журнала в `results.xlsx`.

## Входные файлы

Положите файлы в рабочую папку приложения:

- `students.xlsx` — листы названы по группам; в первой строке заголовки, в колонках A и B — фамилия и имя.
- `tickets.docx` — билеты в формате `Билет N` и нумерованные абзацы с вопросами. В билет включаются первые три вопроса; записи с менее чем тремя вопросами пропускаются.

Если источники отсутствуют или не читаются, веб-страница покажет понятную ошибку. `results.xlsx` создаётся при первом запуске с заголовками, если его ещё нет.

## Запуск веб-приложения

Из папки проекта выполните:

```powershell
cargo run -- --web
```

Откройте <http://127.0.0.1:8080>. Выберите группу и студента, затем нажмите «Сгенерировать билет». После показа результата нажмите `Esc` или кнопку выбора другого студента; приложение останется открытым.

Первое назначение выбирает билет случайно. Для повторного выбора того же студента сохраняется номер из первой записи, а в журнал добавляется отдельная строка с пометкой «да». Все новые записи сразу дописываются в конец `results.xlsx`.

Если `results.xlsx` открыт в Excel, закройте его и повторите генерацию после отображения ошибки сохранения.

## Тестирование

```powershell
cargo test
```

Тесты проверяют веб-страницу и её элементы выбора/возврата, получение групп и студентов через веб-маршруты, повторное назначение с сохранением истории, обработку отсутствующих файлов и разбор билетов.

Для браузерного UI E2E-теста нужны Google Chrome, совместимый с ним ChromeDriver, запущенный на порту `9515`, и приложение на `http://127.0.0.1:8080`. Подготовьте `students.xlsx` и `tickets.docx` в рабочей папке приложения и запустите сервисы в отдельных терминалах:

```powershell
chromedriver.exe --port=9515
```

```powershell
cargo run -- --web
```

В третьем терминале выполните:

```powershell
cargo test --test ui_e2e -- --ignored
```

E2E-тест сам выбирает первую доступную группу и первого студента, назначает билет и **добавляет запись в `results.xlsx`** работающего приложения. Для безопасного прогона используйте отдельную папку с копиями входных файлов, чтобы не менять рабочий журнал.

## Журнал результатов

| Колонка | Содержимое |
| --- | --- |
| A | Группа |
| B | Фамилия |
| C | Имя |
| D | Номер билета |
| E | Дата и время |
| F | Повтор (`да` / `нет`) |
