# 🎟️ Ticket Generator (Генератор экзаменационных билетов)

Веб-приложение и система автоматизации для проведения экзаменационных сессий, разработанная на **Rust** с использованием современного веб-интерфейса и сквозным (E2E) тестированием.

## 📌 Назначение программы

Программа предназначена для автоматизации распределения экзаменационных билетов среди студентов, интерактивного выбора групп, генерации случайных вопросов/номеров билетов и ведения защищенного учета в формате Excel.

---

## ⚙️ Основные возможности и архитектура

* **🌐 Веб-интерфейс на Rust:** Переход от нативного интерфейса к легковесному локальному серверу позволяет управлять приложением через привычные браузеры.
* **🟦 Интеллектуальный рандомайзер:** Автоматический выбор группы, студента и генерация случайного значения билета.
* **🟩 Мгновенное сохранение (Fault Tolerance):** Данные записываются в Excel-журнал сразу после генерации. При аварийном завершении работы данные не теряются.
* **🟧 Защита от блокировки файлов:** Если файл журнала занят в Microsoft Excel, приложение корректно обрабатывает ошибку доступа, предотвращая аварийное падение.
* **🧪 Автоматизированные E2E-тесты:** Полноценное покрытие интерфейса сквозными тестами на базе Rust (`thirtyfour` + Selenium ChromeDriver), имитирующими реальные действия пользователя.

---

## 📋 Формат журнала результатов (`results.xlsx`)

Приложение автоматически создает файл журнала, если он отсутствует, и дописывает новые данные в конец без перезаписи предыдущих сессий:

| Колонка A | Колонка B | Колонка C | Колонка D |
| :--- | :--- | :--- | :--- |
| **Группа** | **Фамилия, Имя** | **Номер билета** | **Дата и время** |
